# Third-party notices

Third-party licenses remain in the source tree beside their components. The UI notice collection is candidate/app-source/customer-docs/UI-THIRD-PARTY-NOTICES.txt. Font licenses, reviewed skill licenses and vendored terminal-helper notices are retained where present. Omarchy's retained license is candidate/base/fixtures/LICENSE.omarchy.txt; that fixture license does not authenticate production Omarchy source.

Required upstream copyright names and email addresses are preserved verbatim. They are attribution, not owner/customer information.

Scope: this document does not enumerate the exact installed OS package inventory, applicable corresponding-source obligations, all installed runtime transitive notices, or target-selected Python notices. The existing UI collection identifies optional-platform texts not locally available. Root package metadata alone is not a full redistribution audit, and this document makes no claim about branding, image or native strategy source rights.
