What this stage changes

Setup prepares the runtime and the Decrypt app under your local account. It shows you the plan before it asks for administrator access.

The password prompt stays in the terminal. This page never asks for or records a password.

Closing this page does not stop installation. Keep the setup terminal open. When setup finishes, press Return there to close it.

Installation notice

If setup stops

Keep the setup folder and the terminal open. They hold the record of what happened.

Cancelled before installing? Run setup again; it reviews the prepared files first. Installation already started? Run the verify step before retrying. Do not reinstall over a partial installation.
